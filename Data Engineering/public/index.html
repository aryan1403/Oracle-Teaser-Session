Exercise 2

Transactional Outbox Pattern vs. Dual-Write CDC Flow

Demonstrates transaction atomicity. In Dual-Write mode, a transaction tries to commit and publish simultaneously. If the streaming broker is offline, the DB transaction rolls back completely to avoid data drift. In Outbox Pattern, DB updates and outbox log insertion commit atomically, and the GoldenGate CDC Agent async relays the updates.
